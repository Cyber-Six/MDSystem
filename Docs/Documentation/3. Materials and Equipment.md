# 3. Materials and Equipment

## 3.1 Hardware Requirements

### 3.1.1 Production Server

| Component | Specification | Purpose |
|---|---|---|
| **Raspberry Pi 5 8GB RAM** | Broadcom BCM2712, 2.4 GHz Quad-Core Cortex-A76, 8 GB LPDDR4X RAM | Main single-board computer running the backend API servers, PostgreSQL database, Redis cache, and serving the compiled web portal assets. The 8 GB RAM variant supports concurrent database operations, background job processing, and real-time WebSocket connections. |
| **NVMe SSD (2TB)** | PCIe Gen 3 via Raspberry Pi 5 M.2 HAT | Primary persistent storage for the PostgreSQL database (medical records, consultation histories, audit logs), uploaded media files (dental photos, document scans), compiled web portal assets, and application logs. The 2TB capacity accommodates projected multi-year data growth. |
| **DeskPi Lite Pi5 Case** | Aluminum case with active cooling fan and heatsink | Thermal management enclosure protecting the Raspberry Pi 5 from overheating during sustained database workloads and concurrent API request processing. |
| **27W USB-C PD Power Supply** | Official Raspberry Pi 5 power supply, 27W USB-C Power Delivery | Dedicated power supply providing stable voltage for the Raspberry Pi 5 and connected NVMe SSD, ensuring uninterrupted server operation. |
| **Optional: HDD 4TB for Backup** | External USB 3.0 HDD, 4TB capacity | Secondary backup storage for daily automated PostgreSQL database dumps and media file mirrors, providing disaster recovery capability. |

**Estimated Initial Hardware Cost:** ₱22,000 – ₱34,250
