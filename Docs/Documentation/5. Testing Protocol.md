# 5. Testing Protocol

## 5.1 Test Approach

The MDSystem testing strategy employs a multi-layered approach covering unit testing, integration testing, API testing, end-to-end functional testing, security testing, and performance validation. Testing is conducted across all four application layers: Backend API, Patient Web Portal, Staff Web Portal, and Mobile Application.

## 5.2 Test Environment

| Environment | Purpose | Configuration |
|---|---|---|
| **Development** | Developer workstation testing | Local PostgreSQL + Redis, mock external services |
| **Staging** | Pre-production integration testing | Raspberry Pi 5, production-mirrored database, real external services |
| **Production** | Live environment | Raspberry Pi 5, production database, all external services active |

## 5.3 Unit Testing

### 5.3.1 Mobile Application Unit Tests

The `mds-mobile` application uses **Jest 29** with `jest-expo` and React Testing Library for component and logic testing.

| Test Target | Test File | Scope |
|---|---|---|
| Core service initialization | `__tests__/core.test.ts` | Token service, Axios handler, banner service factory creation |
| Token storage operations | `__tests__/services/token-service.test.ts` | Token CRUD, namespace isolation, validation |
| Axios request handler | `__tests__/services/axios-request-handler.test.ts` | Interceptors, 401 retry, banner triggers |
| Health chat service | `__tests__/services/health-chat-service.test.ts` | GraphQL query construction, response parsing |
| Appointment service | `__tests__/services/appointment-service.test.ts` | Booking flow, slot availability queries |
| Email validation | `__tests__/validation/email-validation.test.ts` | TIP email patterns (student, employee, medical) |
| Password validation | `__tests__/validation/password-validation.test.ts` | Length, complexity, match rules |

**Run mobile tests:**
```bash
cd mds-mobile && npm test
```

### 5.3.2 Backend Logic Testing

Backend logic is tested through direct API endpoint testing (see Section 5.4) since the backend uses raw SQL queries without an ORM layer that would benefit from isolated unit testing.

## 5.5 Security Testing

### 5.5.1 Authentication Security Tests

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| SEC-01 | Access protected endpoint without JWT | 401 Unauthorized |
| SEC-02 | Access staff endpoint with patient JWT | 403 Forbidden |
| SEC-03 | Replay expired access token | 401 Unauthorized, triggers refresh attempt |
| SEC-04 | Brute-force login (10+ failed attempts) | Progressive lockout + reCAPTCHA requirement |
| SEC-05 | Manipulate JWT payload (alter userId) | 401 Signature verification failed |
| SEC-06 | Reuse revoked refresh token | 401 All sessions invalidated (reuse detection) |
| SEC-07 | Staff session anchor (`sid`) mismatch | 401 Session invalidated |

### 5.5.2 Input Validation Security Tests

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| SEC-08 | SQL injection in search query | Parameterized query blocks injection |
| SEC-09 | XSS payload in chat message | `xss` library sanitizes HTML |
| SEC-10 | Path traversal in file upload (`../../etc/passwd`) | `safeResolve()` blocks traversal |
| SEC-11 | Upload executable disguised as image (wrong magic bytes) | `file-type` validation rejects file |
| SEC-12 | Oversized file upload (exceeding multer limit) | 413 Payload Too Large |
| SEC-13 | Cross-origin request from unauthorized domain | CORS policy blocks request |

### 5.5.3 Rate Limiting Tests

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| SEC-14 | Exceed patient authentication rate limit | 429 Too Many Requests with retry-after |
| SEC-15 | Exceed staff API rate limit | 429 with appropriate backoff window |
| SEC-16 | Rate limit cooldown and recovery | Requests resume after cooldown period |

### 5.5.4 RBAC Permission Tests

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| SEC-17 | Staff without `emr_allow_view` accesses EMR | Permission denied |
| SEC-18 | Staff without `inventory_allow_dispense` dispenses medicine | Permission denied |
