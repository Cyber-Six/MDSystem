## Abstract

**Abstract —** The Medical-Dental Services (MDS) of the Technological Institute of the Philippines (TIP) relies on a manual, paper-based system for managing student and employee health records, resulting in operational inefficiencies, fragmented data access, delayed reporting, and risks of non-compliance with the Philippine Data Privacy Act of 2012 (R.A. 10173). This project presents MDSystem, a full-stack, multi-platform Electronic Medical Record (EMR) system designed to digitize and centralize the clinic's medical and dental record workflows. The system comprises a Node.js/Express 5 backend API serving both REST and GraphQL endpoints, backed by PostgreSQL (60+ tables, 40+ enum types) and Redis; two React 19 web portals for patients and medical staff; a React Native/Expo mobile application; and a shared ESM core package using factory-based dependency injection for cross-platform code reuse. Key features include a dual-server architecture with role-segregated JWT authentication and 40+ RBAC permission keys, RFC 6238 TOTP two-factor authentication with AES-256 encryption, ICD-10/ICD-11 diagnosis coding via WHO API integration, real-time health chat via Socket.IO with Redis pub/sub adapter and offline notification queuing, a medical inventory management system with batch-level tracking and stock reservation, dynamic analytics with 30+ configurable queries exportable as PDF, Excel, and CSV, and a document generation subsystem for prescriptions, medical certificates, and clinical reports. The system was successfully implemented and deployed on a Raspberry Pi 5 server, addressing all functional and non-functional requirements specified in the Software Requirements Specification.

**Keywords:** *Electronic Medical Record, EMR, Medical-Dental Services, TIP, GraphQL, React, React Native, Expo, Node.js, PostgreSQL, Socket.IO, RBAC, JWT, TOTP, ICD-10*
