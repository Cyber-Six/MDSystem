SECURITY FEATURES

JWT Authentication:
    • Access tokens - Short-lived, role-based expiration
    • Refresh tokens - 7 days default, Redis-backed
    • Separate expiration for Patient vs Staff roles

Password Security:
    • bcrypt hashing - 12 salt rounds
    • Length requirements - 8-64 characters

Rate Limiting:
    • IP-based limiting - Redis counters
    • Role-based profiles - Different limits per user type
    • Portal-based limiting - Patient vs Staff portals

Additional Security:
    • XSS protection - Sanitization library
    • Input validation - validator.js
    • Timing attack prevention - Random auth delays
    • reCAPTCHA - Google v2/v3
    • CORS - Configured allowed origins
    • Cloudflare WAF - DDoS & web application firewall
