7. AUTHENTICATION & SECURITY

JWT Configuration
────────────────────────────────────────

    Access Tokens
        Implementation: Short-lived (configurable per role)

    Refresh Tokens
        Implementation: Long-lived (approximately 7 days default)

    Token Storage
        Implementation: Redis-backed sessions

    Role-based expiration
        Implementation: Patient vs Staff tokens


Password Security
────────────────────────────────────────

    Hashing
        Implementation: bcrypt with 12 salt rounds

    Minimum length
        Value: 8 characters

    Maximum length
        Value: 64 characters


Rate Limiting
────────────────────────────────────────

    IP-based limiting
        Implementation: Redis-backed counters

    Role-based profiles
        Implementation: Different limits per user type

    Portal-based limiting
        Implementation: Patient vs Staff portals


Security Features
────────────────────────────────────────

    XSS Protection
        Implementation: xss sanitization library

    Input Validation
        Implementation: validator.js library

    Timing Attack Prevention
        Implementation: Random delay on auth failures

    reCAPTCHA
        Implementation: Google reCAPTCHA v2/v3

    CORS
        Implementation: Configured allowed origins

    Cloudflare
        Implementation: DDoS protection & WAF

12. ENVIRONMENT VARIABLES REQUIRED

Backend (.env)
────────────────────────────────────────

Database Configuration:
    POSTGRES_HOST=
    POSTGRES_USER=
    POSTGRES_PASSWORD=
    POSTGRES_DB=
    POSTGRES_PORT=5432

Redis Configuration:
    REDIS_HOST=127.0.0.1
    REDIS_PORT=6379
    REDIS_USERNAME=
    REDIS_PASSWORD=
    REDIS_DB=0

JWT Configuration:
    JWT_SECRET=
    JWT_PATIENT_ACCESS_EXPIRATION=
    JWT_STAFF_ACCESS_EXPIRATION=
    JWT_REFRESH_EXPIRATION=604800

Email Configuration:
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=465
    SMTP_SECURE=true
    SMTP_USER=
    SMTP_PASS=
    EMAIL_DELAY=1000

OTP Expiration (in seconds):
    EMAIL_VERIF_EXPIRATION=300
    EMAIL_2FA_EXPIRATION=300
    EMAIL_PASSWD_RESET_EXPIRATION=900

reCAPTCHA Configuration:
    RECAPTCHA_SECRET_KEY=
    RECAPTCHA_TEST_MODE=false

Server Configuration:
    HOST=
    PATIENT_PORT=3001

Logging Configuration:
    LOGGER_DIR=logs
    LOG_LEVEL=info


Frontend (.env.local)
────────────────────────────────────────

    VITE_DEV_PORTAL=www
